            SEC // 04 · CORE_CAPABILITIES
          

        

      


      

        

          

            Core Capabilities
          

          

            Dibangun untuk alur kerja yang nyata.
          

          

            Bukan sekadar hit endpoint: SonicPoint memahami kode, schema, dan data milikmu — lalu melaporkan apa adanya.
          

        


        

          
          

            

              

                
              

              AST Walker
            

            

              Scan dari AST
            

            

              Endpoint ditemukan dari kode: mount prefix diikuti, import relatif di-resolve, dan import melingkar tidak membuat scanner tersesat.
            

          


          
          

            

              

                
              

              AI + Fallback
            

            

              Payload dari schema validasimu
            

            

              Joi, Zod, dan Yup dipindai menjadi field required/optional beserta constraint. AI mengisi payloadnya; tanpa AI, fallback deterministik tetap jalan.
            

          


          
          

            

              

                
              

              Live ID Cache
            

            

              Relasi yang tidak dikarang
            

            

              itemId dan lahanId disampel dari collection GET milikmu, di-cache sekali, lalu di-refresh otomatis saat terbukti basi. Nol data palsu.
            

          


          
          

            

              

                
              

              Bearer Token
            

            

              Auth-aware
            

            

              Login sekali lewat login endpoint, token diambil dari tokenField, lalu dipakai sebagai Bearer di semua request — termasuk saat sampling.
            

          


          
          

            

              

                
              

              Unified REPL
            

            

              Satu prompt untuk semuanya
            

            

              /scan, /schema, /context, /test, /report, dan /config bekerja tanpa keluar dari REPL — memakai engine yang sama dengan command mode.
            

          


          
          

            

              

                
              

              Swagger-like UI
            

            

              Laporan yang jujur
            

            

              Request body, respons, status, dan latensi per endpoint dalam satu halaman ala Swagger. Yang gagal ditulis gagal, yang di-skip menyebut alasannya.

            SEC // 09 · TRANSPARENCY_FAQ
          

        

      


      

        

          

            

              Transparency & Docs
            

            

              Pertanyaan umum & batasan yang kami akui.
            

            

              Kami percaya developer tool harus jujur soal apa yang sudah bisa dilakukan dengan sangat baik dan batasan arsitektur saat ini.
            


            

              
Batasan Saat Ini (v1.4.2)

              
    
                
  • • Fokus penuh pada ekosistem Express.js (Fastify & Hono masih dalam roadmap).
    • 
                
  • • Resolusi modul mengutamakan import relatif standar & path alias TypeScript dasar.
    • 
                
  • • Endpoint upload multipart/binary dilewati secara default kecuali dikonfigurasi.
    • 
              

            

          


          

            
            

              
              

                Tetap jalan 100%. SonicPoint memiliki Deterministic Fallback Generator yang membaca tipe data, panjang minimal/maksimal, regex, enum, dan format email langsung dari AST Joi/Zod/Yup tanpa memanggil LLM sama sekali.
              

            


            
            

              
              

                Secara default, SonicPoint menyalakan guard skipDelete: true. Semua route DELETE akan dicatat di laporan sebagai SKIPPED beserta alasan eksplisit agar tidak menghapus data referensi yang sedang dipakai sampling.
              

            


            
            

              
              

                Engine mencocokkan nama field pada schema atau parameter URL (misalnya lahanId, user_id, atau :itemId) terhadap daftar route koleksi GET yang ditemukan saat proses AST scan, lalu menyampel respons array/pagination-nya.
              

            


            
            

              
              

                Tidak. AST parsing terjadi 100% lokal di mesinmu. Yang diterbitkan ke link laporan hanyalah metadata rute, payload uji, status HTTP, latensi, dan potongan respons JSON (dengan header sensitif yang disamarkan).
              

            

          

        

      

    


    
    

      
      

        

        

        

        

        

          

          

        

      


      

        

          Siap mencoba di repo Express-mu?
        

        

          Instal secara global atau jalankan via npx, arahkan ke aplikasimu, dan bagikan laporan pertamamu dalam hitungan detik.
